# Round 01 — CLEAR

입문자가 공식 미션을 바탕으로 단계별로 따라가며 미션을 완료합니다.

## 선행 학습

- **필수 선행 미션:** 없음
- **권장 선행 미션:** B2-2
- **있으면 좋은 선행 지식:** Git diff/commit, HTTP API, JSON, 환경변수/API Key 개념

B2-2에서 Git branch/commit/PR 협업 흐름을 먼저 경험하면 B6-2의 Git 기반 AI 보조 도구가 어떤 시점에 동작하는지 이해하기 쉽습니다. Git 기본 흐름을 이미 알고 있다면 B2-2를 CLEAR하지 않고도 B6-2를 시작할 수 있습니다.

진행 순서: `START-CHECK.md` → Mission 확인 → 용어/개념 → 환경 → 구현 → 검증 → Evidence → CLEAR.

핵심 문서:
- `START-CHECK.md` — Git/API/JSON/Secret 시작 전 자가진단
- `BEGINNER-GUIDE.md`
- `CHECKLIST.md`

`START-CHECK.md`는 공식 Gate가 아니라 부족한 Git/API 개념을 미리 찾고 필요한 부분만 보충하기 위한 안내입니다.

상세 폴더와 파일은 실제로 필요해지는 시점에만 생성합니다.
