# B6-2 — 시작 전 지식 체크

이 문서는 B6-2를 시작하기 전에 **Git 변경 이력과 AI API 호출을 이해하기 위한 최소 지식**이 준비되어 있는지 확인하는 자가진단입니다. 공식 평가나 Runtime Gate가 아닙니다.

## 선행 학습

- **필수 선행 미션:** 없음
- **권장 선행 미션:** B2-2
- **있으면 좋은 선행 지식:** Git diff/commit, HTTP API, JSON, 환경변수/API Key 개념

## 자가진단

- [ ] `git diff`가 변경된 코드를 보여 준다는 점을 이해한다.
- [ ] commit과 branch의 기본 역할을 알고 있다.
- [ ] HTTP API가 요청을 보내고 응답을 받는 방식이라는 점을 이해한다.
- [ ] JSON이 key-value 형태의 데이터 표현 방식이라는 점을 알고 있다.
- [ ] API Key가 외부 서비스 인증에 사용되는 Secret이라는 점을 이해한다.
- [ ] 환경변수에 Secret을 넣고 소스 코드에는 직접 쓰지 않아야 하는 이유를 알고 있다.

## 판단 방법

- 대부분 `예`라면 `BEGINNER-GUIDE.md`로 바로 진행합니다.
- Git diff/commit 흐름이 낯설다면 B2-2의 Git 기본 흐름을 먼저 복습하면 좋습니다.
- API/JSON이 처음이어도 B6-2에서 필요한 범위부터 학습할 수 있으므로 시작을 막지 않습니다.

> **B2-2 CLEAR는 필수 조건이 아닙니다.** Git과 API의 기본 개념을 이미 이해한다면 바로 B6-2에 진입할 수 있습니다.
