# B3-2 — 시작 전 지식 체크

이 문서는 B3-2를 시작하기 전에 **Git의 이력 개념과 자료구조·정렬 사고가 준비되어 있는지** 확인하기 위한 자가진단입니다. 공식 평가나 Runtime Gate가 아닙니다.

## 선행 학습

- **필수 선행 미션:** 없음
- **권장 선행 미션:** B3-1, B2-2
- **있으면 좋은 선행 지식:** Git commit/branch/history, Graph/DAG, 정렬 알고리즘 기초

## 자가진단

- [ ] Git commit이 특정 시점의 변경 이력을 기록한다는 점을 이해한다.
- [ ] branch가 서로 다른 작업 흐름을 나누는 개념임을 설명할 수 있다.
- [ ] 부모 commit과 자식 commit의 관계를 대략 이해한다.
- [ ] Graph와 DAG(Directed Acyclic Graph)라는 용어를 본 적이 있다.
- [ ] 정렬 알고리즘이 데이터를 일정 기준으로 재배치한다는 점을 이해한다.
- [ ] Python의 클래스·리스트·반복문을 읽고 수정할 수 있다.

## 판단 방법

- 대부분 `예`라면 `BEGINNER-GUIDE.md`로 바로 진행합니다.
- Git history가 낯설다면 B2-2의 commit/branch/merge 흐름을 먼저 복습하면 좋습니다.
- 자료구조 구현이 낯설다면 B3-1의 HashMap/Linked List/Heap 학습 경험이 도움이 됩니다.

> **B3-1이나 B2-2 CLEAR가 필수는 아닙니다.** 필요한 개념을 이미 알고 있다면 바로 B3-2를 시작할 수 있습니다.
